# Gunita: Reaper of Echoes

> _The dead have stories to tell. Will you listen?_

Gunita: Reaper of Echoes is a browser-based 2D narrative adventure built with Phaser.js and Vite. You play as Vino, a newly appointed Echo Reaper, as you investigate forgotten memories trapped within Campo Lunan, solve AI-generated riddles, and restore Philippine-inspired stories to peace.

![Gunita main menu](src/assets/main-menu/main-menu-reference.png)

## About The Game

Gunita blends exploration, investigation, and memory restoration into a story-driven experience inspired by Philippine heritage. Each memory world is built around folklore, traditions, historical imagery, and emotional storytelling.

The core loop is simple:

Campo Lunan -> Choose a grave -> Enter a memory world -> Explore -> Use Echo -> Find memory fragments -> Solve riddles -> Restore memories -> Reveal the story -> Free the soul

## Features

- AI-powered riddles, hints, and dialogue
- Exploration-focused memory worlds
- Hidden Memory Fragments and artifact restoration
- Philippine-inspired environments and stories
- Atmospheric pixel-art presentation with fog, lighting, and UI effects

## How To Play

1. Start in Campo Lunan and approach a glowing Dambana to begin an investigation.
2. Enter a memory world through the Portada.
3. Search the environment for Memory Fragments and hidden clues.
4. Use Echo to reveal nearby secrets.
5. Answer AI-generated riddles to restore fragments.
6. Recover every memory to uncover the soul’s full story.
